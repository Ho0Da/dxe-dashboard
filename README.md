# DXE Team Workload

داشبورد التيم، بتتحدث من ClickUp مرتين في اليوم (11:53 و 19:53 بتوقيت الرياض، من الأحد للخميس) عن طريق GitHub Actions، ومنشورة على GitHub Pages. كل ده مجاني ومش مرتبط بـ Claude.

## خطوات الرفع (مرة واحدة بس)

1. **اعملي حساب على GitHub** من github.com لو مش عندك.

2. **اعملي repository جديد:**
   - اضغطي **New repository**.
   - الاسم: `dxe-dashboard`.
   - اختاري **Public**، لأن GitHub Pages المجانية بتشتغل مع الـ public بس.
   - اضغطي **Create repository**.

3. **ارفعي الملفات:**
   - اضغطي **uploading an existing file**.
   - اسحبي كل اللي جوه الفولدر: `site` و `scripts` و `people.json` و `README.md`.
   - اضغطي **Commit changes**.

4. **ضيفي ملف التحديث التلقائي.** الفولدر `.github` ساعات بيبقى مخفي ومش بيترفع بالسحب، فاعمليه بإيدك:
   - اضغطي **Add file → Create new file**.
   - في خانة الاسم اكتبي `.github/workflows/update.yml`.
   - افتحي الملف ده من الفولدر اللي معاكي، وانسخي كل اللي فيه وحطيه في الصفحة.
   - اضغطي **Commit changes**.

5. **هاتي مفتاح ClickUp (API Token):**
   - في ClickUp اضغطي على صورتك.
   - اختاري **Settings → Apps**.
   - في **API Token** اضغطي **Generate**.
   - انسخي الكود اللي بيبدأ بـ `pk_`.

6. **حطي المفتاح في GitHub:**
   - من الـ repository روحي على **Settings → Secrets and variables → Actions**.
   - اضغطي **New repository secret**.
   - الاسم: `CLICKUP_TOKEN`، والقيمة: الكود اللي نسختيه.
   - اضغطي **Add secret**.

7. **شغّلي الصفحة:**
   - روحي على **Settings → Pages**.
   - في **Source** اختاري **GitHub Actions**.

8. **أول تحديث:**
   - روحي على تبويب **Actions**.
   - لو ظهر زرار التفعيل، فعّلي الـ workflows.
   - اختاري **Update dashboard**، واضغطي **Run workflow**.
   - بعد دقيقتين تلاتة اللينك هيبقى `https://<اسم-حسابك>.github.io/dxe-dashboard/` وده اللي تبعتيه للـ CTO.

## تعديلات بعد كده

- **حد جديد في التيم أو حد غيّر تيمه:** عدّلي `people.json`.
  - كل سطر فيه: رقم الشخص في ClickUp، ثم الحرف المختصر، ثم الاسم، ثم التيم (`ksa` أو `eg`).
  - أي حد مش موجود في الملف بيتحسب على مصر لوحده.
- **عايزة تخفي حد:** ضيفي الحرف المختصر بتاعه في `removed`.
- **تحديث فوري:** من Actions اختاري **Update dashboard** واضغطي **Run workflow**.

## حاجات مهمة

- **المفتاح مربوط بحسابك في ClickUp.** الداشبورد بتشوف بس التاسكات اللي حسابك شايفها، ولو الحساب اتقفل التحديث هيقف. ممكن بعدين تحطوا مفتاح حساب خدمة تبع الشركة بدله.
- **الـ repository عام.** أي حد يوصل له يقدر يشوف ملف البيانات (الأسماء وعدد التاسكات)، بس مش هيقدر يوصل لـ ClickUp لأن المفتاح متخزن كـ secret ومش ظاهر.
- **التحديث من غير حدود.** السكريبت بيكلم ClickUp API مباشرة، فمفيش حد الـ 100 طلب في اليوم، والأرقام كلها مظبوطة بالتاريخ الفعلي، ومنها Came in لكل شهر.
